# 🎁 Ad Popup Slacker

[English](README.en.md) | [简体中文](README.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md)

> どんなWebページも「ポップアップ広告」に偽装します。枠なし・常に最前面・ごちゃごちゃの広告まみれで、本物のページは広告の中にこっそり隠れています。上司が通りかかったら、ワンキーで非表示。

[Electron](https://www.electronjs.org/) 製です。ページは偽の「広告動画エリア」に埋め込まれ、周囲には赤い封筒のバナー、商品カード、大きな「今すぐ受け取る」ボタンが並び、その上に「広告 AD」の透かしと HOT／タイムセールのステッカーが重なります。遠くから見れば、誰も見たくない迷惑広告にしか見えません。

## ✨ 機能

- **広告に擬態**：赤橙のストライプ見出し、舞い落ちる赤い封筒、点滅する商品カード、揺れる「今すぐ受け取る」ボタン、偽の「閉じる」カウントダウン。ウィンドウタイトルは「期間限定特価」。
- **枠なし＋常に最前面**：OSのタイトルバーも枠もなく、最上位レイヤーで表示、タスクバーには非表示。起動のたびに画面のランダムな位置に現れ、上部のグレーのバーでドラッグできます。
- **グローバルなボスキー**：どのアプリ上でも `Alt+Q` で即座に非表示／再表示。他のソフトに使われている場合に備え、予備キーを2つ用意。
- **本物のページを広告に紛れ込ませる**：ページは偽の動画エリア内にあり、透かし・ステッカー・偽のプレーヤーバーが重なりますが、クリックやスクロールはそのままページに届きます。
- **ズーム自動調整**：ウィンドウ幅に合わせてページの拡大率が自動で変わるため、ウィンドウをリサイズしてもデスクトップ版のレイアウトが保たれます。
- **偽のプレーヤーバーが本物のリモコン**：▶ 再生／一時停止、‹ 前へ、「スキップ ›」で次の動画へ。ショート動画に便利です。
- **自動再生**：自動再生の制限を解除済みで、次の動画もクリックなしで再生されます。
- **アプリ起動をブロック**：`bytedance://` などのカスタムプロトコルへの遷移を破棄し、「このリンクを開くアプリを取得」というシステムダイアログを出しません。
- **デスクトップ版／モバイル版 UA をワンキーで切り替え**。

## 🚀 クイックスタート

### 方法1：インストーラをダウンロード

[Releases](https://github.com/ll2310782478/ad-popup-slacker-app/releases) ページから、お使いのOS向けのインストーラ（Windows `.exe`、macOS `.dmg`、Linux `.AppImage`）をダウンロードします。

> インストーラにはコード署名がありません。Windows では SmartScreen の警告が出る場合があるので、「詳細情報 → 実行」を選んでください。macOS では初回のみ右クリック → 開く、または `xattr -cr "/Applications/Ad Popup Slacker.app"` を実行してください。

### 方法2：ソースから実行

[Node.js](https://nodejs.org/) 18 以上が必要です。

```bash
git clone https://github.com/ll2310782478/ad-popup-slacker-app.git
cd ad-popup-slacker-app
npm install
npm start
```

URL を指定して起動することもできます：

```bash
npm start -- https://www.douyin.com
```

ウィンドウが表示されたら、下部の「🎁 クーポンコード」に偽装した入力欄に URL（または検索語）を入力して Enter を押します。

### 自分でビルドする

```bash
npm run dist     # 成果物は dist/ に出力されます
```

`v*` タグを push すると、GitHub Actions が Windows / macOS / Linux 向けにビルドし、Release を公開します：

```bash
git tag v1.0.0 && git push --tags
```

## ⌨️ ショートカット

| ショートカット | 動作 | 範囲 |
| --- | --- | --- |
| `Alt+Q` | ウィンドウの表示／非表示（ボスキー） | グローバル |
| `Ctrl+Alt+Q`、`Ctrl+Shift+Z` | 予備のボスキー | グローバル |
| `Esc` | ウィンドウを非表示 | ウィンドウ内 |
| 右上の「閉じる ✕」をクリック（5秒のカウントダウン後） | ウィンドウを非表示 | ウィンドウ内 |
| `↑` / `↓` | 前／次の動画 | ウィンドウ内 |
| `Ctrl+L` | URL 入力欄にフォーカス | ウィンドウ内 |
| `Ctrl+U` | デスクトップ版／モバイル版の切り替え | ウィンドウ内 |
| `Ctrl+=` / `Ctrl+-` | ページ内容を拡大／縮小 | ウィンドウ内 |
| `Ctrl+0` | 拡大率をリセット | ウィンドウ内 |

### ボスキーを変更する

環境変数 `BOSSKEY` でメインのショートカットを指定できます（書式は [Electron Accelerator](https://www.electronjs.org/docs/latest/api/accelerator) を参照）：

```bash
# macOS / Linux
BOSSKEY="Control+Shift+X" npm start

# Windows PowerShell
$env:BOSSKEY="Control+Shift+X"; npm start
```

起動後、ターミナルに実際に登録されたショートカットが表示されます。「登録失敗」と出た場合は、予備キーも他のソフトに使われているため、別の組み合わせを指定してください。

## 🔧 仕組み

| ファイル | 説明 |
| --- | --- |
| `main.js` | メインプロセス：枠なし最前面ウィンドウの作成、グローバルショートカットの登録、カスタムプロトコルのブロック、ページ内のキー入力の転送 |
| `preload.js` | `contextBridge` 経由で `hide()` とホットキーのコールバックを UI に公開 |
| `index.html` | 広告 UI とロジック：擬態スタイル、`<webview>`、ズーム自動調整、偽のプレーヤーバー |
| `.github/workflows/` | `build.yml` はタグでビルド＆リリース、`ci.yml` は構文チェック |

**ズーム自動調整**：拡大率 ＝ 動画エリアの幅 ÷ 目標ビューポート幅（既定 700）。0.25〜2 の範囲に制限され、`ResizeObserver` でリサイズのたびに再計算します。`Ctrl+=` / `Ctrl+-` は目標ビューポート幅を変更します。

## ⚠️ 既知の制限

- 排他的フルスクリーンのゲームの上には表示できません。
- 管理者権限で動作するプログラムが前面にあると、通常権限のこのアプリはグローバルショートカットを受け取れない場合があります。その場合は管理者としてターミナルを開いてから `npm start` してください。
- macOS では `Option+Q` がシステムに使われている場合があります。`BOSSKEY` で `Control+Shift+Z` などに変更してください。
- 主に Windows で開発・テストしており、macOS / Linux は十分に検証していません。
- サイトによっては埋め込みブラウザを検出・制限したり、ログインが必要だったりします。
