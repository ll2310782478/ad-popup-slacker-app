# 🎁 Ad Popup Slacker

[English](README.en.md) | [简体中文](README.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | **한국어**

> 어떤 웹페이지든 "팝업 광고"로 위장합니다. 테두리 없음, 항상 맨 위, 정신없는 광고 투성이 속에 진짜 웹페이지가 몰래 숨어 있습니다. 상사가 지나가면 키 하나로 바로 숨기세요.

[Electron](https://www.electronjs.org/) 기반입니다. 웹페이지는 가짜 "광고 영상 영역"에 들어가고, 그 주위에 빨간 봉투 배너, 상품 카드, 커다란 "지금 받기" 버튼이 놓이며, 그 위에 "광고 AD" 워터마크와 HOT／타임세일 스티커가 겹쳐집니다. 멀리서 보면 아무도 보고 싶지 않은 악성 광고로만 보입니다.

## ✨ 기능

- **광고로 위장**: 빨강·주황 줄무늬 제목, 떨어지는 빨간 봉투, 깜빡이는 상품 카드, 흔들리는 "지금 받기" 버튼, 가짜 "닫기" 카운트다운. 창 제목은 "한정 특가".
- **테두리 없음 + 항상 위**: OS 제목 표시줄과 테두리가 없고, 최상위 레벨로 표시되며, 작업 표시줄에는 나타나지 않습니다. 실행할 때마다 화면의 임의 위치에 나타나며, 상단 회색 줄을 잡고 끌 수 있습니다.
- **전역 보스 키**: 어떤 프로그램에서든 `Alt+Q`로 즉시 숨기기／다시 보이기. 다른 프로그램이 단축키를 쓰고 있을 때를 대비해 예비 키 2개를 함께 등록합니다.
- **진짜 웹페이지를 광고 속에 숨김**: 페이지는 가짜 영상 영역 안에 있고 워터마크, 스티커, 가짜 플레이어 바가 덮이지만, 클릭과 스크롤은 그대로 페이지에 전달됩니다.
- **확대/축소 자동 조정**: 창 너비에 맞춰 페이지 배율이 자동으로 바뀌므로, 창 크기를 조절해도 데스크톱 같은 레이아웃이 유지됩니다.
- **가짜 플레이어 바가 진짜 리모컨**: ▶ 재생/일시정지, ‹ 이전, "건너뛰기 ›" 다음 영상. 숏폼 영상에 편리합니다.
- **자동 재생**: 자동 재생 제한을 해제하여 다음 영상도 클릭 없이 재생됩니다.
- **앱 실행 차단**: `bytedance://` 같은 사용자 지정 프로토콜 이동을 차단하여 "이 링크를 열 앱 찾기" 시스템 대화상자가 뜨지 않습니다.
- **데스크톱／모바일 UA를 키 하나로 전환**.

## 🚀 빠른 시작

### 방법 1: 설치 파일 다운로드

[Releases](https://github.com/ll2310782478/ad-popup-slacker-app/releases) 페이지에서 사용하는 OS에 맞는 설치 파일(Windows `.exe`, macOS `.dmg`, Linux `.AppImage`)을 받으세요.

> 설치 파일은 코드 서명이 되어 있지 않습니다. Windows에서는 SmartScreen 경고가 나올 수 있으니 "추가 정보 → 실행"을 누르세요. macOS에서는 처음 한 번 우클릭 → 열기를 하거나 `xattr -cr "/Applications/Ad Popup Slacker.app"`을 실행하세요.

### 방법 2: 소스에서 실행

[Node.js](https://nodejs.org/) 18 이상이 필요합니다.

```bash
git clone https://github.com/ll2310782478/ad-popup-slacker-app.git
cd ad-popup-slacker-app
npm install
npm start
```

URL을 지정해서 바로 실행할 수도 있습니다:

```bash
npm start -- https://www.douyin.com
```

창이 나타나면 하단의 "🎁 쿠폰 코드"로 위장한 입력란에 URL(또는 검색어)을 입력하고 Enter를 누르세요.

### 직접 빌드하기

```bash
npm run dist     # 결과물은 dist/ 에 생성됩니다
```

`v*` 태그를 push하면 GitHub Actions가 Windows / macOS / Linux용으로 빌드하고 Release를 게시합니다:

```bash
git tag v1.0.0 && git push --tags
```

## ⌨️ 단축키

| 단축키 | 동작 | 범위 |
| --- | --- | --- |
| `Alt+Q` | 창 숨기기／보이기 (보스 키) | 전역 |
| `Ctrl+Alt+Q`, `Ctrl+Shift+Z` | 예비 보스 키 | 전역 |
| `Esc` | 창 숨기기 | 창 안 |
| 오른쪽 위 "닫기 ✕" 클릭 (5초 카운트다운 후) | 창 숨기기 | 창 안 |
| `↑` / `↓` | 이전／다음 영상 | 창 안 |
| `Ctrl+L` | URL 입력란에 포커스 | 창 안 |
| `Ctrl+U` | 데스크톱／모바일 페이지 전환 | 창 안 |
| `Ctrl+=` / `Ctrl+-` | 페이지 내용 확대／축소 | 창 안 |
| `Ctrl+0` | 배율 초기화 | 창 안 |

### 보스 키 변경

환경 변수 `BOSSKEY`로 기본 단축키를 지정할 수 있습니다 (형식은 [Electron Accelerator](https://www.electronjs.org/docs/latest/api/accelerator) 참고):

```bash
# macOS / Linux
BOSSKEY="Control+Shift+X" npm start

# Windows PowerShell
$env:BOSSKEY="Control+Shift+X"; npm start
```

실행 후 터미널에 실제로 등록된 단축키가 출력됩니다. "등록 실패"가 나오면 예비 키까지 모두 다른 프로그램이 사용 중이라는 뜻이니 다른 조합을 지정하세요.

## 🔧 동작 원리

| 파일 | 설명 |
| --- | --- |
| `main.js` | 메인 프로세스: 테두리 없는 항상 위 창 생성, 전역 단축키 등록, 사용자 지정 프로토콜 차단, 페이지 내부 키 입력 전달 |
| `preload.js` | `contextBridge`로 `hide()`와 단축키 콜백을 UI에 노출 |
| `index.html` | 광고 UI와 로직: 위장 스타일, `<webview>`, 확대/축소 자동 조정, 가짜 플레이어 바 |
| `.github/workflows/` | `build.yml`은 태그 푸시 시 빌드·릴리스, `ci.yml`은 문법 검사 |

**확대/축소 자동 조정**: 배율 = 영상 영역 너비 ÷ 목표 뷰포트 너비(기본 700). 0.25~2 범위로 제한되며 `ResizeObserver`로 창 크기가 바뀔 때마다 다시 계산합니다. `Ctrl+=` / `Ctrl+-`는 목표 뷰포트 너비를 조절합니다.

## ⚠️ 알려진 제한 사항

- 독점 전체 화면 게임 위에는 표시할 수 없습니다.
- 관리자 권한으로 실행 중인 프로그램이 앞에 있으면, 일반 권한으로 실행된 이 앱은 전역 단축키를 받지 못할 수 있습니다. 이 경우 터미널을 관리자 권한으로 열고 `npm start`를 실행하세요.
- macOS에서는 `Option+Q`를 시스템이 사용할 수 있습니다. `BOSSKEY`로 `Control+Shift+Z` 같은 조합으로 바꾸세요.
- 주로 Windows에서 개발·테스트했으며 macOS / Linux는 충분히 검증하지 않았습니다.
- 일부 사이트는 내장 브라우저를 감지하거나 제한하거나 로그인이 필요할 수 있습니다.

## 📜 면책 조항

이 프로젝트는 기술 학습과 개인적인 즐거움을 위한 것입니다. 소속 회사나 학교의 규정 및 관련 법령을 지키는 범위에서 사용하세요. **업무, 수업, 시험 등 집중이 필요한 상황에서는 사용을 권장하지 않습니다.** 이 도구를 사용하여 발생하는 모든 결과는 사용자 본인의 책임입니다.
